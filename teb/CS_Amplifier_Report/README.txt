>>> IMPORTANT #1 -- THE Q2/Q3/Q4 HAND-CALCULATION VALUES <<<
------------------------------------------------------------
Section 5 of the report answers Q2, Q3 and Q4 using this design point:

    Q2, Q3:  ID = 500 uA, VOV = 0.25 V, unCox = 200 uA/V^2,
             upCox = 100 uA/V^2, |VTH| = 0.5 V, L = 180 nm
    Q4:      ID = 100 uA, VOV = 0.2 V, lambda = 0.05 V^-1, RD = 18 kohm

YOU SHOULD KNOW: these values are NOT in the assignment. The assignment sheet
states only the performance targets (gain >= 15 dB, power <= 1 mW,
BW >= 100 MHz, CL = 50 fF, Lmin = 180 nm). Q3 says "set the quiescent drain
current to the required value" -- it never names 500 uA. Q4 says "calculate
the input and output impedances, DC gain, and 3-dB frequency theoretically" --
it gives no numbers at all.

Every one of those values appears in your senior's report
(Common_Source_Amplifier_23116075.pdf) as that student's OWN choices:
"Take ID = 0.5 mA and VOV = 0.25 V", "Assume ID = 100 uA, Vov = 0.2 V",
"Assuming lambda = 0.05 V^-1", "If RD = 18 kohm".

So the report labels Section 5 as a "hand-calculation design point" and
registers it as assumption A9 -- it does NOT claim the assignment prescribed
these numbers, because that claim is checkable and false.

Two things were deliberately done differently from the senior's version:
  - Q4 output resistance: 18k||200k = 16.514 kohm (the senior's report rounds
    this to 16.3 kohm, which is arithmetically wrong). Gain 24.36 dB, not
    24.2 dB.
  - Q3 mirror ratio: the senior uses a 1:1 mirror with IREF = 500 uA. That
    draws 1 mA total = 1.8 mW and BREAKS the 1 mW spec. This report uses a
    10:1 mirror with IREF = 50 uA, RREF = 21 kohm, total 990 uW -- which
    actually meets the specification.

If you would rather not use these values at all, say so and they can be
re-derived from your own measured operating points instead.


>>> IMPORTANT #2 -- THE RECONSTRUCTED PLOTS <<<
------------------------------------------------
The nine Cadence screenshots you supplied contain the schematics, the DC
operating points, the DC sweep, and the AC MAGNITUDE responses. They do NOT
contain any phase plot or any transient plot.

The assignment requires both. So the following seven figures are ANALYTICAL
RECONSTRUCTIONS, computed from the dominant-pole small-signal model using your
measured mid-band gain, measured -3 dB frequency and measured quiescent
operating point as the only inputs:

    phase_res.pdf     phase_active.pdf     phase_diode.pdf
    tran_res.pdf      tran_active.pdf      tran_diode.pdf
    compare_bode.pdf

They are NOT simulator output. Each one carries a visible on-figure stamp
saying so, each caption says so, and Appendix A of the report
(items A4, A5, A6) records it again.

If your lab expects these plots to be real Spectre captures, re-run the two
analyses in Cadence and swap the real screenshots in. The model predicts what
you should see, so they are a good cross-check:

  - AC phase: should sit at -180 deg in mid-band and pass -225 deg at
    1.03276 GHz (A), 218.483 MHz (B), 1.89606 GHz (C).
  - Transient at 10 MHz: inverted output, Vout_pp = 142.93 mV (A),
    339.64 mV (B), 36.60 mV (C) for Vin_pp = 20/20/10 mV.

Appendix A of the report also records these other assumptions:
  A1  process constants (mu*Cox, lambda, Cox) -- the SCL model card is
      proprietary, so standard published 180 nm values were used, and ONLY
      in the "theoretical" columns.
  A2  the current-mirror bias networks were designed on paper to answer Q3;
      the simulated schematics use ideal vdc/vpulse gate sources.
  A3  the W/L ratios of the IMPLEMENTED circuits were back-calculated from
      the annotated gm and ID, because the W and L fields are not visible in
      the screenshots.
  A9  the Q2/Q3/Q4 hand-calculation design point (see IMPORTANT #1 above).
